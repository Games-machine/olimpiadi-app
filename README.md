# Olimpiadi — simulatore di gare

Versione eseguibile del gioco: https://games-machine.github.io/olimpiadi-app/

Simula gare sportive (100 metri, maratona, ciclismo, automobilismo, sci) con
partecipanti dalle caratteristiche configurabili, qualificazioni e animazione.
Tutto gira nel browser; i dati restano nel localStorage.

Questo repository contiene solo i file necessari all'esecuzione, generati
automaticamente dal sorgente.
